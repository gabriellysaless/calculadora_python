# 🧮 Calculadora em Python

Projeto desenvolvido durante o primeiro módulo do curso de **Backend com Python pela EBAC**, com o objetivo de praticar os fundamentos da linguagem e a lógica de programação.

## 📌 Sobre o projeto

Calculadora executada pelo terminal que permite realizar operações matemáticas básicas entre dois números.

O usuário escolhe a operação desejada, informa os valores e recebe o resultado. Também é possível realizar várias operações sem precisar reiniciar o programa.

## ⚙️ Funcionalidades

- Soma;
- Subtração;
- Multiplicação;
- Divisão;
- Validação de operações não listadas;
- Verificação de divisão por zero;
- Opção para continuar realizando operações.

## 🛠️ Tecnologias e conceitos utilizados

- **Python**
- Variáveis e tipos de dados;
- Entrada de dados com `input()`;
- Conversão de tipos com `float()`;
- Estruturas condicionais (`if`, `elif` e `else`);
- Estrutura de repetição (`while`);

## ▶️ Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd nome-da-pasta
   ```

3. Execute o arquivo Python:

   ```bash
   python calculadora.py
   ```
